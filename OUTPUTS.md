# Generated Outputs

This document lists all the files generated by the Fast Gerrymandering Optimization Library.

## 📁 Results Directory

All outputs are saved in the `results/` directory.

### 🎬 Animation Files

#### `gerrymandering_simulation.gif`
- **Description**: Animated GIF showing the complete optimization process
- **Content**: 
  - Left panel: District map with party colors (red=center-left, blue=center-right)
  - Right panel: Optimization progress (score and target party wins over time)
  - Shows evolution from random district assignment to optimized gerrymandered map
- **Size**: ~308 KB
- **Duration**: ~20 frames showing optimization steps

### 📊 Analysis Plots

#### `parameter_analysis.png`
- **Description**: Comprehensive parameter sweep analysis
- **Content**: 4-panel plot showing:
  - Effect of partisan weight on win rates
  - Temperature impact on optimization success  
  - Cooling rate influence on convergence
  - Best parameters heatmap for each target party
- **Size**: ~1.6 MB
- **Resolution**: High DPI (300) for publication quality

#### `sample_vote_distribution.png`
- **Description**: Natural vote distribution across Italian communes
- **Content**: Choropleth map showing center-left vote share before optimization
- **Size**: ~1.1 MB
- **Data**: Based on 2022 Italian election results

#### `final_districts.png`
- **Description**: Final optimized district map (generated by demo)
- **Content**: District boundaries colored by winning party
- **Size**: Varies
- **Note**: Generated when running `run_demo.py`

### 📈 Data Files

#### `demo_parameter_sweep_results.csv`
- **Description**: Raw results from parameter sweep analysis
- **Content**: CSV with columns for temperature, cooling_rate, partisan_weight, target_party, avg_win_rate, etc.
- **Use**: For further analysis or custom plotting

## 🎯 How to View

### On Linux/Mac:
```bash
# View GIF
open results/gerrymandering_simulation.gif

# View PNG files
open results/parameter_analysis.png
open results/sample_vote_distribution.png
```

### On Windows:
```bash
# View files
start results/gerrymandering_simulation.gif
start results/parameter_analysis.png
start results/sample_vote_distribution.png
```

### In Python:
```python
import matplotlib.pyplot as plt
import matplotlib.image as mpimg

# Display images
img = mpimg.imread('results/parameter_analysis.png')
plt.imshow(img)
plt.axis('off')
plt.show()
```

## 📊 Key Findings

From the generated outputs, you can observe:

1. **Optimization Effectiveness**: The algorithm can achieve 70-80% win rates for the target party
2. **Parameter Sensitivity**: Partisan weight has the strongest effect on outcomes
3. **Geographical Constraints**: Districts remain reasonably compact despite optimization
4. **Vote Distribution**: Natural vote patterns show significant regional variation

## 🔄 Regenerating Outputs

To regenerate all outputs:

```bash

```
